# שיא הנחלה, נתיבות – דף נחיתה לקמפיין פייסבוק

דף נחיתה סטטי (HTML/CSS/JS, ללא פריימוורק) לפרויקט **שיא הנחלה** של שיא רפאל פרוייקטים בע״מ, בעיצוב של עמוד הפרויקט באתר היזם (נייבי וזהב, מסגרת מעוגלת).
תוספות להמרה: טופס לידים עם Webhook, פס פעולות דביק במובייל (שיחה / וואטסאפ / טופס), וואטסאפ צף, תפיסת UTM ואירועי פיקסל.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | הדף עצמו |
| `css/style.css` | עיצוב (RTL, רספונסיבי) |
| `js/config.js` | **כל ההגדרות שצריך לשנות**: טלפון, וואטסאפ, יעד הלידים, פיקסל |
| `js/main.js` | טופס, ולידציה, UTM, טאבים של תוכניות, גלריה |
| `scripts/localize-assets.sh` | העתקת התמונות מאתר היזם לתיקייה מקומית |

## לפני העלאה לאוויר (5 דקות)
1. **וואטסאפ** – ב-`js/config.js` החלף את `whatsapp` למספר הנייד של המכירות בפורמט בינלאומי (למשל `972501234567`).
2. **יעד הלידים** – הגדר `leadWebhook`. הטופס שולח `POST` עם JSON:
   ```json
   { "name": "...", "phone": "...", "email": "...", "rooms": "4 חדרים",
     "project": "שיא הנחלה - נתיבות", "source": "hero",
     "utm_source": "facebook", "utm_campaign": "...", "page": "...", "time": "..." }
   ```
   עובד עם Make / Zapier (Webhook), Google Apps Script, Monday, Powerlink, או כל CRM שמקבל Webhook.
   כל עוד השדה ריק, הדף במצב הדגמה: הליד נרשם ב-console של הדפדפן ומוצגת הודעת הצלחה.
3. **פיקסל** – `facebookPixelId` (וגם `gtmId` אם יש). הדף יורה אוטומטית `PageView`, `Lead` בהצלחת טופס, ו-`Contact` בלחיצה על טלפון/וואטסאפ.
4. **תמונות** – כרגע נטענות ישירות מ-crp.co.il. לפרודקשן מומלץ להריץ `bash scripts/localize-assets.sh` כדי שהדף לא יהיה תלוי באתר החברה.
5. **robots** – הדף מסומן `noindex` (דף קמפיין). אם רוצים אינדוקס, הסר את תגית ה-meta ב-`index.html`.
